# 영어 읽기 도구, 스마트폰에서 보기 — GitHub Pages 설정 가이드

`F:\EnglishGame` 폴더는 서버가 필요 없는 순수 HTML/JS 파일 모음이라, GitHub Pages 같은 무료 정적 호스팅에 그대로 올리면 됩니다. 계정 생성부터 폰에서 열어보기까지 순서대로 따라 하시면 됩니다.

## 1단계 — GitHub 계정 만들기

1. 브라우저에서 `github.com` 접속.
2. 오른쪽 위 **Sign up** 클릭.
3. 이메일 주소(brian.spbae@gmail.com 사용 가능), 비밀번호, 사용자 이름을 정하고 가입 절차를 마칩니다. 완전히 무료입니다.

이미 계정이 있으면 이 단계는 건너뛰고 로그인만 합니다.

## 2단계 — 새 저장소(repository) 만들기

1. 로그인 후 오른쪽 위 **+** 버튼 → **New repository** 클릭.
2. Repository name에 `english-game` 정도로 이름을 정합니다 (원하는 이름 아무거나 가능).
3. **Public**으로 설정합니다. GitHub Pages 무료 기능은 Public 저장소에서만 됩니다 — 다만 URL을 직접 알려주지 않는 한 다른 사람이 우연히 찾아올 일은 거의 없습니다.
4. 다른 옵션은 그대로 두고 **Create repository** 클릭.

## 3단계 — 파일 업로드

1. 방금 만든 저장소 페이지에서 **Add file → Upload files** 클릭.
2. `F:\EnglishGame` 폴더를 열어서 다음을 통째로 화면에 드래그해서 올립니다:
   - `red-headed-league.html`
   - `word-game` 폴더 전체 (폴더째로 드래그하면 안의 파일 구조가 그대로 유지됩니다)
   - `PROJECT.md` (선택 — 없어도 동작에는 지장 없음)
3. 아래 **Commit changes** 버튼을 눌러 업로드를 완료합니다.

나중에 대목을 추가하는 등 파일이 갱신되면, 저장소에서 해당 파일을 열어 **Edit** (연필 아이콘)로 내용을 바꾸거나, 같은 방식으로 **Upload files**로 재업로드하면 자동으로 덮어써집니다.

## 4단계 — GitHub Pages 켜기

1. 저장소 상단 메뉴에서 **Settings** 클릭.
2. 왼쪽 메뉴에서 **Pages** 클릭.
3. **Branch** 항목에서 `main`과 `/ (root)`를 선택하고 **Save**를 누릅니다.
4. 1~2분 정도 기다리면 페이지 위쪽에 "Your site is live at https://사용자이름.github.io/english-game/" 같은 안내가 뜹니다.

## 5단계 — 폰에서 열기

주소창에 다음과 같은 형태로 입력합니다 (실제 사용자 이름과 저장소 이름으로 바꿔서):

```
https://사용자이름.github.io/english-game/red-headed-league.html
```

단어 게임은 읽기 페이지의 "단어 게임 ↗" 링크를 누르면 자동으로 연결됩니다.

스마트폰 브라우저에서 이 주소를 연 뒤, 공유 버튼 → "홈 화면에 추가"를 하면 앱 아이콘처럼 홈 화면에 놓고 바로 열 수 있습니다.

## 알아둘 점 — 진행 상황은 기기별로 따로 저장됩니다

이 도구는 읽은 위치·복습 기록을 브라우저의 로컬 저장소(localStorage)에 저장합니다. 이는 **기기(브라우저)마다 따로** 저장되는 방식이라, PC 크롬에서 읽은 진도와 폰 사파리/크롬에서 읽은 진도는 서로 자동으로 합쳐지지 않습니다. 즉:

- PC에서 읽던 걸 이어서 폰에서 보고 싶다면, 폰에서도 처음부터 다시 진도가 쌓입니다.
- 한쪽 기기만 계속 쓰기로 정하면 문제없이 이어집니다.
- 나중에 진도를 기기 간에 동기화하고 싶다면 별도 저장 방식(예: 클라우드 저장, 로그인 기능)이 필요한데, 이는 지금 구조보다 훨씬 복잡해지는 작업이라 필요해지면 별도로 설계하는 게 좋습니다.
